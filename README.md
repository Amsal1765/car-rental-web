Вебзастосунок для оренди автомобілів
Опис проєкту
Вебзастосунок призначений для пошуку та оренди автомобілів через інтернет. Користувачі зможуть переглядати каталог автомобілів, ознайомлюватися з їхніми характеристиками, вибирати дати оренди та оформлювати бронювання.
Технології
Frontend: React, JavaScript
Backend: C#, ASP.NET Core
База даних: MySQL
Основні функції
Перегляд каталогу автомобілів.
Пошук, фільтрація та сортування автомобілів.
Реєстрація та авторизація користувачів.
Перегляд характеристик автомобілів.
Вибір дат оренди та розрахунок вартості.
Оформлення та перегляд бронювань.
Особистий кабінет користувача.
Панель адміністратора для керування автомобілями та бронюваннями.
Статус проєкту
Проєкт перебуває на етапі планування та підготовки технічного завдання. Розробка функціоналу запланована на наступних етапах.
Призначення
Навчальний проєкт для виконання курсової роботи з розробки вебзастосунку.
